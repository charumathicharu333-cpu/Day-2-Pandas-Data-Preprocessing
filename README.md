# 📊 Day 2 – Pandas Data Pre-processing

## 📌 Project Overview

This beginner-level project demonstrates how to pre-process tabular data using Python, Pandas, NumPy, and Scikit-learn.

Data pre-processing is an important step in Machine Learning. It helps clean and prepare raw data before training a model.

## 🎯 Objectives

- Handle missing values
- Detect and remove outliers
- Encode categorical features
- Separate features and target
- Split the dataset into training and testing data

## 🛠️ Technologies Used

- Pandas

- Scikit-learn

## 📋 Dataset Description

The sample dataset contains student information.

| Column | Description |
|---|---|
| Name | Student name |
| Age | Student age |
| Marks | Student marks |
| Department | Student department |

## 🔄 Pre-processing Steps

### 1. Dataset Creation
Created a sample student dataset using Pandas.

### 2. Handling Missing Values
Replaced missing marks (`NaN`) with the average marks using `fillna()`.

### 3. Outlier Removal
Removed an unrealistic age value using a filtering condition.

### 4. Categorical Encoding
Converted department names into numerical values using `LabelEncoder`.

### 5. Feature and Target Separation
Separated input features (`X`) and target variable (`y`).

### 6. Train-Test Split
Divided the dataset into training and testing data using `train_test_split()`.

## 📈 Final Result

- Missing values handled successfully
- Outlier removed
- Categorical data encoded
- Dataset split into training and testing sets
- Pre-processing completed successfully
